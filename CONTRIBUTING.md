# Contributing

Use Node.js 20 or newer. The tool has no runtime dependencies or build step.

```sh
npm test
npm start
npm pack --dry-run
```

Run a project on a separate port to check iframe integration and the adapter.
Check phone viewport sizing, gestures, and PNG/JSON export when changing the UI.
Use synthetic examples and fixtures; do not include credentials or personal data.

Keep the English and Chinese README files consistent with behavior. Describe
the problem, resulting behavior, and validation in pull requests. Contributions
are licensed under the repository's MIT license.
