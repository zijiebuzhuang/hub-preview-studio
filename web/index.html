Connect your project

Run your project separately, then enter its URL above. For glasses output, install this package in the project and choose the preview bridge only in development:

import { createPreviewBridge, isStudioPreview }
  from 'hub-preview-studio/client';

const bridge = import.meta.env.DEV && isStudioPreview()
  ? createPreviewBridge()
  : await waitForEvenAppBridge();

The bridge supports text, lists, inline PNG images, text replacement and simulated gestures. Preview storage is volatile; audio and sensors are unsupported. Pages that disallow iframe embedding must be adjusted in your dev server.
